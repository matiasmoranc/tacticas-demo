# Laboratorio táctico — Mercado Élite 5

Demo independiente para probar el sistema de formaciones libres antes de integrarlo al juego principal.

## Mecánica

- Cuatro jugadores de campo distribuibles entre defensa, medio y ataque.
- Las 15 combinaciones posibles, desde `4-0-0` hasta `0-0-4`.
- Cada jugador utiliza el atributo de la zona que ocupa.
- Una línea vacía conserva un valor mínimo de 5.
- El mediocampo aporta un 30% a ataque y defensa.
- El arquero aporta un 15% a la defensa.
- La calidad original del plantel genera una ventaja de 0, 3, 5 o 7 puntos.
- Un cambio táctico por equipo después de comenzar el partido.

La versión publicable está en `dist/`.
